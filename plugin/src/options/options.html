控制面板显示与字幕抓取行为。

在视频页右下角显示等级胶囊，点击展开完整面板。
默认在视频页右侧垂直居中显示。在页面上直接拖动胶囊即可移动，松手后位置会自动记住（按屏幕比例保存，换分辨率也不跑偏）。
关闭后只在点击扩展图标时分析。
开启时只分析英语字幕；若视频只有中文字幕，会明确提示「无法评估英文生词量」。
低于此词数会标注「样本偏小，仅供参考」。
在 YouTube / 哔哩哔哩 播放器字幕上逐词上色：生词红色、在学蓝色、未收录橙色。对着字幕直接点词即可看离线释义、改标记。未联动墨读词库时不着色（避免满屏标记反而看不清字幕）。
字幕背景复杂，建议保留 着色 + 下划线；如果画面花，可换「底色」提高对比度。

网页文章

除视频外，普通网页的英文文章也能分析——还能进入「阅读模式」逐词着色、点词查离线释义。

关闭后不再抽取正文（内容脚本仍会注入，但不做任何事）。
识别到文章时，在右下角显示评级胶囊；点开可进入阅读模式。
把「已学」的词压暗，只突出在学 / 生词本 / 未收录的词，适合集中攻生词。
13–26 px。
阅读模式里的释义来自墨读自带离线词典（本地服务的 /dict/<字母>.json）， 不需要联网、也不需要额外安装词典；墨读没运行时只着色、不显示释义。

网页上色与标记

不必进阅读模式——直接在网页正文上给生词着色；点词看释义、随手标记；选中句子可以划线。

只给没掌握的词着色（在学 / 生词本 / 未收录），已学的词保持原样——满屏着色比不标更伤阅读。
下划线最不扰人；底色在深色页面上更醒目。
选中一段文字 → 浮动工具条「划线」，像微信读书那样在原文上留痕。

词标记会像「手动校正词库」一样参与所有页面与视频的判定。
支持站点不止新闻/博客：微信读书（weread.qq.com）、Z-Library / Anna's Archive 等阅读器、各类期刊杂志的正文页都已内置容器识别；识别不到时会退回通用正文抽取。 标记与划线都只存本机浏览器，不上传。

等级口径

三套体系各自衡量什么，以及它们之间怎么对应。

① 阶梯阅读法 L1–L4（看「对你」）

L1 轻松可理解度 ≥98% · 自由阅读区
L2 适中95–98% · i+1 理想区（最值得看）
L3 偏难90–95% · 教学挑战区
L4 困难<90% · 挫败区

② CEFR A1–C2（看文本）

A1 / A2前 2500 高频词覆盖率 ≥ 94% / ≥ 87% · 入门–基础
B1≥ 75% · 中级（能读懂要点）
B2≥ 62% · 中高级（抽象话题增多）
C1 / C2≥ 46% / < 46% · 高级–精通（术语与抽象密集）

③ 蓝思 Lexile（看文本）

≤ 400L启蒙–小学低段 · 极短句、绘本
400–800L小学高段–初中 · 分级读物、青少年小说、日常 vlog
800–1000L高中 · 新闻、传记、一般科普
> 1000L大学以上 · 社论、专业文章、学术论文

「可理解度」＝（已学词次 + 在学词次）÷ 总词次，与墨读阅读端的书籍难度统计完全同口径， 所以视频、文章与电子书的 L1–L4 可以直接横向比较。 CEFR 与蓝思则脱离你的词库，只反映材料本身的用词难度——蓝思值用的是 「平均词频对数」近似法（MetaMetrics 的官方公式未公开），锚点与校验样本见 plugin/tools/calibrate-rating.mjs。
